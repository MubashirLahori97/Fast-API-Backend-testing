## Metadata

Each file opens with a YAML header. Please carry these fields into the knowledge base:

- `audience: clinician` — all seven lessons are clinician-level content, distinct from the patient course and books.
- `content_types` — the kinds of material the file contains (education, lab interpretation, supplement protocol, Rx overview, product).
- `replaced_by` — these files are to be removed when *The Hypothalamus Primer* is ingested. Please make sure content can be swapped out, not only added.

## Inline labels

Statements and sections carry labels in square brackets. Please preserve them in chunking, since they control how content may be used.

| Label | Meaning |
| --- | --- |
| [Established] | Consensus physiology or guideline-level evidence |
| [Emerging] | Supported by recent research, often animal or early human data; not yet standard of care |
| [Clinical observation] | Deborah's clinical experience since 1997; stated as experience, not proof |
| [Rx overview] | Prescription medication content, written as an overview for integrative practice |
| [Product] | Genesis Gold, Sacred Seven, or other Genesis Health Products content |

## Rules for app use

1. **Rx overview content** is for clinician-level explanation only. For app users, present it only as options to discuss with their own provider. Never present doses, schedules, or routes as instructions to a user.
2. **Supplement doses** may be shared as general information with a recommendation to check with a provider, especially when the user takes prescription medications, is pregnant or breastfeeding, or is managing a chronic condition.
3. **[Emerging] and [Clinical observation]** content should be described as such in answers ("research suggests," "in Deborah's clinical experience"), never as settled fact.
4. **[Product]** content uses structure/function language only. Do not restate it as treating, curing, or preventing a disease.
5. **When patient and clinician content overlap**, use the patient course and books for the user-facing voice, and this content for depth and for the "For your provider" section of printable summaries.
